# Bio-Age Chiron — Major 1 (9.10.0-major1, versionCode 910)

Полный визуальный редизайн существующего приложения. Данные, ключи хранения, импорт Apple Health, подпись и applicationId не менялись.

## Что сделано
- Горная сцена Three.js переписана (`assets/three_caucasus/index.html`): процедурный двуглавый массив в стиле Эльбруса, снег/скалы, закатное небо, облака, одна автоматическая камера, без жестов. Это стилизация, не точная модель.
- Причины «пустого голубого фона» устранены: сцена ждёт ненулевого размера WebView, камера и туман перенастроены, горы контрастны небу; без WebGL рисуется 2D-панорама тех же гор; под WebView лежит Compose-фон с горами.
- Четыре экрана в едином стиле (`M1Theme.kt`, `M1Screens.kt`), связь со сценой (`M1Scene.kt`), чтение данных (`M1Data.kt`).
- Только реальные значения: HRV и пульс покоя — из импорта Apple Health, сон/шаги — из ручных записей. Восстановление, нагрузка, биологический возраст — «—»/«Нет данных» (расчёты — Major 2).
- Исправлен скрытый сбой на Android 8–9: `ChironStore(...).use {}` (AutoCloseable только с API 29).

## Не проверено
Работа на реальном телефоне (Android WebView, производительность, шрифт 1.3, экран 360dp). Сцена проверена в настольном Chromium.
