# Bio-Age Alpha 0.5 — исходники от ChatGPT

## Что меняется
- `elbrus_terrain.glb`: новый процедурный 3D-рельеф с двумя вершинами, шумом склонов и цветами скал/снега. Это стилизованная модель, **не точная геодезическая копия Эльбруса**. Существующий `Caucasus3DScene.kt` загружает этот же путь, поэтому код сцены менять не нужно.
- `.github/workflows/android.yml`: обязательная подпись APK одним постоянным ключом, хранящимся только в GitHub Actions Secrets. Без секретов сборка завершится ошибкой, а не выдаст APK с непостоянной подписью.
- `apply_alpha05.py`: обновляет `versionCode` до 5 и `versionName` до `0.5.0-alpha`, не меняя applicationId и локальное хранилище.

## Claude: точная последовательность
1. Внести файлы ZIP в корень репозитория, выполнить `python3 apply_alpha05.py`.
2. **До запуска Actions** один раз создать отдельный постоянный keystore локально в защищённой среде, например `keytool -genkeypair -v -keystore bioage-release.jks -storetype PKCS12 -alias bioage -keyalg RSA -keysize 3072 -validity 10000`. Пароли не помещать в репозиторий, логи, чат или коммиты.
3. В GitHub Actions repository secrets установить `BIOAGE_KEYSTORE_BASE64` (base64 содержимого keystore без переносов), `BIOAGE_KEYSTORE_PASSWORD`, `BIOAGE_KEY_PASSWORD`, `BIOAGE_KEY_ALIAS`. Для PKCS12 key password обычно равен store password. **Нельзя помещать keystore в публичный репозиторий.** Если у Claude нет доступа к Secrets, попросить пользователя установить их через GitHub UI или подготовить безопасную альтернативу. Не сообщать пароли в чат.
4. Сохранить резервную копию keystore и паролей в защищённом месте вне GitHub. Потеря ключа лишит возможности обновлять установленный APK без удаления.
5. Выполнить сборку, проверить `apksigner verify`, проверить подпись нового APK и `versionCode`.
6. ВАЖНО: если Alpha 0.4 подписана другим ключом, переход на Alpha 0.5 потребует **однократного удаления** старого приложения. До этого сделать резервное копирование данных, если они важны. Начиная с 0.5, APK с тем же постоянным ключом должны устанавливаться поверх, если versionCode растёт и applicationId не меняется.

## Ограничения
- Настоящее небо, свет, туман и тени требуют дополнительной настройки SceneView/Filament; в этом патче они **не реализованы**.
- Android-компиляция здесь не выполнялась; проверены структура ZIP и GLB.
