# Bio-Age Chiron Alpha 7.00 — единый крупный пакет

Основа: актуальный MainActivity.kt версии 6.10 из GitHub на 13.11.2026.

## Установка
Из корня репозитория: `python3 /путь/к/папке/apply.py`.
Скрипт проверяет якоря перед изменением и прекращает работу, если исходники несовместимы.
Сохранён `MainActivity.kt.pre_unified_backup` локально — не коммить его.
Собрать существующим GitHub Actions с постоянным ключом подписи.

## Реализовано в этом пакете
- Перестроенная главная с данными, игровым маршрутом и советом Хирона.
- Анимированное абстрактное энергетическое ядро Хирона (Compose Canvas), без лица.
- Периоды 7/30/90 дней, средние только по записанным дням.
- Прозрачные разделы сна, активности, Recovery/HRV, долголетия с честным состоянием «нет данных».
- Контрольные точки восхождения и недельный ритм.
- Существующие формы ввода, привычки, экспорт/импорт, офлайн Three.js фон и одна автоматическая камера сохранены.
- Никаких новых разрешений, сетевых запросов или изменений ключей хранения.

## НЕ реализовано и НЕ должно изображаться работающим
- Полноценная WHOOP-эквивалентная Recovery/Strain без HRV/пульса.
- Health Connect, синхронизация часов, реальная ИИ-модель Хирона, биологический возраст.
- Полное соответствие 160+ ответам: исходный полный список не извлечён.
- Полная проверка Kotlin/Android и тесты на смартфоне: их должен выполнить сборщик.

## Тесты на устройстве
Проверить главную, здоровье, прогресс, экран Хирона, сохранение дня, старые записи,
экспорт и импорт (не перезаписывать единственную копию), плавность Three.js, отсутствие жестов камеры,
поворот экрана и поведение без записей. Не удалять приложение.
